Sua vez de criar um caso
Pense em um pequeno problema que voce mesmo vive no dia a dia, algo que te incomoda toda semana e que, em
teoria, um sistema poderia ajudar a resolver. Nao precisa ser grande, so real.
1. Empatia. Escreva uma pergunta que voce faria a si mesmo sobre esse problema.
2. Definicao. formule o problema de maneira afirmativa com uma definicao.
3. Ideacao. Liste ao menos tres ideias diferentes de solucao.
4. Escolha. Escolha uma das tres ideias para levar adiante.
5. Historia de usuario. Escreva tres historias de usuario da ideia escolhida, no formato como, quero, para.
6. Criterio de aceitacao. Escreva tres criterios de aceitacao da ideia escolhida, no formato dado, quando, entao.   

Minha resposta:

Empatia: Por que eu nao consigo decorar informacoes como cpf, rg etc, mesmo usando sempre e sendo tao importante?

Definicao: O problema é que eu não está forte o suficiente o caminho da informação no meu cérebro.

Ideação:1 Aplicativo que carrega informações importantes e senhas. 2 Aplicativo para decorar números e textos. 3 Software que traz suas informações do governo para a tela.

Escolha: A opção 2, pois da para fazer offline, personalizado, muito mais simples, seguro e mais útil pois será importante fora do dispositivo do software, em todo o lugar, até mesmo sem dispositivos eletronicos envolvidos.

História de usuário: 1 Como usuário do app, quero poder cadastrar textos e numeros, para registrar o que quero memorizar. 2 Como usuário, quero ter um botão para inicar meu treino, para treinar o caminho dos neuronios. 3 Como usuário, quero que não mostre a informação, a não ser que eu não consiga lembrar, para garantir que não so escrevo o que vejo e só poder ver quando eu realmente não lembrar e melhorar meu treinamento.

Critério de aceitacao: Dado a entrada no app, quando aperto para iniciar o treino, então aparece o nome de cada informação e um espaço de escrita para preencher o dado. Dado o termino do treinamento, quando erro uma informação, então o software não me deixa seguir para a proxima, fala que esta errado e pede para tentar novamente. Dado o usuário não conseguir lembrar, quando aperta no botão de dica, então mostra o proximo algarismo necessário.
